# 🚀 Развертывание черно-белого режима на сервер 192.168.255.137

## 📋 **Команды для развертывания:**

### **1. Скопируйте файлы на сервер:**
```bash
# Скопируйте архив на сервер
scp grayscale_deployment.tar.gz root@192.168.255.137:/var/www/html/
# или если у вас другой пользователь:
scp grayscale_deployment.tar.gz user@192.168.255.137:/path/to/your/project/
```

### **2. На удаленном сервере (192.168.255.137) выполните:**

```bash
# Подключитесь к серверу
ssh root@192.168.255.137
# или
ssh user@192.168.255.137

# Перейдите в папку с проектом
cd /var/www/html/
# или в папку где находится ваш проект

# Остановите текущий сервер
sudo systemctl stop your-flask-app
# или найдите процесс и остановите
ps aux | grep python
kill -9 <PID>

# Создайте резервную копию базы данных
cp dating_app.db dating_app_backup_$(date +%Y%m%d_%H%M%S).db

# Распакуйте архив
tar -xzf grayscale_deployment.tar.gz

# Запустите миграцию (если нужно)
python migrate_add_grayscale_mode.py

# Запустите сервер
python app.py
# или
sudo systemctl start your-flask-app
```

### **3. Тестирование:**

1. Откройте браузер и перейдите на `https://192.168.255.137`
2. Войдите в систему
3. Перейдите в настройки (⚙️)
4. Найдите кнопку черно-белого режима (⚫)
5. Переключите режим и проверьте работу

## 🔧 **Альтернативный способ (если SSH не работает):**

### **Через веб-интерфейс или файловый менеджер:**

1. Загрузите файл `grayscale_deployment.tar.gz` на сервер
2. Распакуйте архив
3. Замените файлы `app.py` и `dating_app.db`
4. Запустите миграцию
5. Перезапустите сервер
