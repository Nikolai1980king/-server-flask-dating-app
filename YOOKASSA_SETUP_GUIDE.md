# 🏦 Руководство по настройке ЮKassa (Яндекс.Касса)

## 📋 Что было реализовано

✅ **Полная интеграция с ЮKassa**:
- Создание платежей через API
- Обработка веб-хуков для подтверждения
- Автоматическая активация профилей после оплаты
- Админ-панель для управления платежами

## 🔧 Настройка ЮKassa

### 1. Регистрация в ЮKassa
1. Перейдите на [yookassa.ru](https://yookassa.ru)
2. Зарегистрируйтесь или войдите в аккаунт
3. Создайте магазин (если еще не создан)

### 2. Получение ключей API
1. В личном кабинете перейдите в **"Настройки" → "API"**
2. Скопируйте:
   - **Shop ID** (идентификатор магазина)
   - **Secret Key** (секретный ключ)

### 3. Настройка веб-хуков
1. В разделе **"Настройки" → "Уведомления"**
2. Добавьте URL веб-хука: `https://ваш-домен.com/yookassa/webhook`
3. Выберите события:
   - `payment.succeeded` (успешная оплата)
   - `payment.canceled` (отмена платежа)
4. Установите **Секретный ключ** для подписи (запомните его!)

### 4. Обновление конфигурации
В файле `app.py` найдите и замените:

```python
# Настройки ЮKassa (Яндекс.Касса)
YOOKASSA_SHOP_ID = "ваш_shop_id"  # Замените на ваш Shop ID
YOOKASSA_SECRET_KEY = "ваш_secret_key"  # Замените на ваш Secret Key
YOOKASSA_WEBHOOK_SECRET = "ваш_webhook_secret"  # Секретный ключ для веб-хуков
PROFILE_CREATION_PRICE = 50.00  # Цена создания профиля в рублях
```

## 💰 Как работает система оплаты

### Пользовательский флоу:
1. **Создание профиля** → Пользователь заполняет анкету
2. **Перенаправление на оплату** → Автоматически перенаправляется на `/payment`
3. **Выбор способа оплаты** → Нажимает "Оплатить 50 ₽"
4. **Переход в ЮKassa** → Перенаправляется на страницу оплаты ЮKassa
5. **Оплата** → Выбирает способ оплаты (карта, СБП, электронные кошельки)
6. **Подтверждение** → ЮKassa отправляет веб-хук на ваш сервер
7. **Активация профиля** → Профиль автоматически активируется
8. **Уведомление** → Пользователь получает уведомление об успешной оплате

### Технические детали:
- **База данных**: Добавлены таблицы `Payment` и поля `is_paid`, `payment_date` в `Profile`
- **Безопасность**: Проверка подписи веб-хуков, защита от повторных платежей
- **Мониторинг**: Админ-панель для отслеживания всех платежей

## 🛠️ Админ-панель

Доступ: `https://ваш-домен.com/admin/payments?key=admin123`

**Функции:**
- Просмотр всех платежей
- Статистика по статусам
- Общая сумма выручки
- Детали каждого платежа

## 🔒 Безопасность

### Рекомендации:
1. **Измените админ-ключ** с `admin123` на более сложный
2. **Используйте HTTPS** для всех запросов
3. **Регулярно проверяйте логи** платежей
4. **Настройте мониторинг** веб-хуков

### Проверка подписи веб-хуков:
```python
def verify_yookassa_webhook(request_data, signature):
    expected_signature = hmac.new(
        YOOKASSA_WEBHOOK_SECRET.encode('utf-8'),
        request_data,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(signature, expected_signature)
```

## 📊 Тестирование

### Тестовый режим:
1. В ЮKassa включите **"Тестовый режим"**
2. Используйте тестовые карты:
   - **Успешная оплата**: `5555 5555 5555 4444`
   - **Отклоненная оплата**: `5555 5555 5555 4445`

### Проверка работы:
1. Создайте тестовый профиль
2. Перейдите на страницу оплаты
3. Используйте тестовую карту
4. Проверьте активацию профиля
5. Посмотрите статистику в админ-панели
