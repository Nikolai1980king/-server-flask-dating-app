# 📱 QR-код для ятута.рф - Руководство

## Что это такое?

QR-код - это специальный квадратный код, который содержит ссылку на ваш сайт **ятута.рф**. Пользователи могут отсканировать его камерой телефона и сразу перейти на ваш сайт.

## Как это работает?

1. **Генерация**: QR-код автоматически генерируется с ссылкой на ваш домен
2. **Сканирование**: Пользователи сканируют код камерой телефона
3. **Переход**: Автоматический переход на ятута.рф

## Где найти QR-код?

### В приложении:
- **Главная страница**: Кнопка "📱 Получить QR-код для ятута.рф"
- **Навигационное меню**: Иконка 📱 в верхней панели
- **Прямая ссылка**: `/qr_code`

### API endpoint:
- **URL**: `/api/qr_code`
- **Формат**: JSON с base64 изображением

## Как выглядит страница QR-кода?

- ✅ Красивый дизайн с градиентом
- ✅ Большой QR-код (300x300 пикселей)
- ✅ Инструкции по использованию
- ✅ Список возможностей приложения
- ✅ Кнопка "На главную"

## Технические детали

### Библиотека:
- **qrcode==7.4.2** - для генерации QR-кодов
- **Pillow** - для обработки изображений

### Функции:
- `generate_qr_code(url, size)` - генерация QR-кода
- `qr_code_page()` - страница с QR-кодом
- `api_qr_code()` - API для получения QR-кода

### Настройки:
- **Размер**: 300x300 пикселей для страницы, 200x200 для API
- **Коррекция ошибок**: L (Low) - 7% повреждений
- **Формат**: PNG с base64 кодированием

## Использование

### Для пользователей:
1. Откройте страницу с QR-кодом
2. Отсканируйте код камерой телефона
3. Переходите на ятута.рф

### Для разработчиков:
```python
# Получение QR-кода через API
import requests
response = requests.get('https://ятута.рф/api/qr_code')
data = response.json()
qr_code_image = data['qr_code']  # base64 изображение
```
