🧪 Тест исправления перенаправления после оплаты

📋 Описание проблемы:

После успешной оплаты пользователь попадал на страницу создания анкеты вместо страницы профиля.

✅ Ожидаемое поведение:

После успешной оплаты пользователь должен попасть на страницу своего профиля (/my_profile).

🔗 Тестовые ссылки:

Нажмите на ссылку ниже, чтобы протестировать страницу успешной оплаты:

🧪 Тест страницы успешной оплаты 👤 Проверить страницу профиля

📝 Инструкции по тестированию:

  1. Нажмите на "Тест страницы успешной оплаты"
  2. Проверьте, что на странице есть кнопка "Перейти к профилю" (НЕ "Создать анкету")
  3. Нажмите на кнопку "Перейти к профилю"
  4. Убедитесь, что вы попали на страницу профиля пользователя

✅ Критерии успеха:

  • ✅ На странице успешной оплаты есть кнопка "Перейти к профилю"
  • ✅ Кнопка ведет на /my_profile
  • ✅ НЕТ кнопки "Создать анкету"

🔧 Дополнительная информация:

URL для тестирования: http://localhost:5000/payment/success?user_id=594247dd-cdad-4845-860d-d142c4183aa5

Ожидаемый редирект: http://localhost:5000/my_profile
