# 🔒 Блокировка ручного ввода в поле "Название заведения"

## ✅ **Что было сделано:**

Поле "Название заведения" теперь **только для чтения** - пользователи не могут вводить текст вручную, название появляется только автоматически при клике на заведение на карте.

## 🔧 **Изменения:**

### **1. Добавлен атрибут `readonly` к полям:**
- ✅ **Создание новой анкеты** (строка 2489)
- ✅ **Редактирование временной анкеты** (строка 4759)  
- ✅ **Редактирование существующей анкеты** (строка 6131)

### **2. Обновлен placeholder:**
```html
<!-- Было: -->
placeholder="Название заведения (кафе, ресторан и т.д.)"

<!-- Стало: -->
placeholder="Выберите заведение на карте"
```

### **3. Добавлены CSS стили для readonly полей:**
```css
/* Стили для readonly полей */
input[readonly] {
    background: rgba(76, 175, 80, 0.05) !important;
    border: 1px solid rgba(76, 175, 80, 0.2) !important;
    color: rgba(255, 255, 255, 0.8) !important;
    cursor: not-allowed;
}

input[readonly]:focus {
    outline: none !important;
    border-color: rgba(76, 175, 80, 0.2) !important;
    box-shadow: none !important;
    background: rgba(76, 175, 80, 0.05) !important;
}
```

## 🎯 **Результат:**

### **Пользователи НЕ МОГУТ:**
- ❌ Вводить текст вручную в поле "Название заведения"
- ❌ Печатать произвольные названия
- ❌ Вводить некорректные данные

### **Пользователи МОГУТ:**
- ✅ Кликать на заведения на карте
- ✅ Автоматически получать правильные названия
- ✅ Видеть подсказку "Выберите заведение на карте"
