# 🚀 Инструкции по развертыванию исправленного кода

## Проблема
Была ошибка: `sqlalchemy.exc.OperationalError: (sqlite3.OperationalError) такого столбца нет: profile.creation_ip`

## Решение
Добавлен столбец `creation_ip` в таблицу `profile` с помощью миграции.

## Файлы для копирования
Создан архив `flask_server_fixed.tar.gz` с исправленными файлами:
- `app.py` - основное приложение с исправлениями
- `migrate_add_creation_ip.py` - скрипт миграции
- `requirements.txt` - зависимости

## Инструкции по развертыванию

### Вариант 1: Автоматическое копирование (если SSH работает)
```bash
# Скопируйте архив на сервер
scp flask_server_fixed.tar.gz root@212.67.11.50:/root/

# Подключитесь к серверу
ssh root@212.67.11.50

# Распакуйте архив
cd /root
tar -xzf flask_server_fixed.tar.gz

# Перейдите в директорию проекта
cd /root/flask_server

# Примените миграцию
python3 migrate_add_creation_ip.py

# Перезапустите приложение
pkill -f 'python.*app.py'
nohup python3 app.py > app.log 2>&1 &
```

### Вариант 2: Ручное копирование
