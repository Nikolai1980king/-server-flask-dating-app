# 🚀 Ручное развертывание черно-белого режима

## **Шаг 1: Скопируйте файлы на сервер**

### **Вариант A: Через SCP (рекомендуется)**
```bash
# Скопируйте обновленный app.py
scp app.py root@192.168.255.137:/var/www/html/

# Скопируйте обновленную базу данных
scp dating_app.db root@192.168.255.137:/var/www/html/

# Скопируйте скрипт миграции
scp migrate_add_grayscale_mode.py root@192.168.255.137:/var/www/html/
```

### **Вариант B: Через веб-интерфейс**
1. Загрузите файлы через веб-интерфейс сервера
2. Или используйте файловый менеджер

### **Вариант C: Через USB/флешку**
1. Скопируйте файлы на флешку
2. Подключите к серверу
3. Скопируйте файлы в папку проекта

## **Шаг 2: Подключитесь к серверу**

```bash
# Подключитесь к серверу
ssh root@192.168.255.137
# или
ssh user@192.168.255.137
```

## **Шаг 3: На сервере выполните команды**

```bash
# Перейдите в папку с проектом
cd /var/www/html/
# или в папку где находится ваш проект

# Остановите текущий сервер
sudo systemctl stop your-flask-app
# или найдите процесс и остановите
ps aux | grep python
kill -9 <PID>

# Создайте резервную копию базы данных
cp dating_app.db dating_app_backup_$(date +%Y%m%d_%H%M%S).db

# Запустите миграцию (добавит поле grayscale_mode)
python migrate_add_grayscale_mode.py

# Запустите сервер
python app.py
# или
sudo systemctl start your-flask-app
```

## **Шаг 4: Тестирование**

1. Откройте браузер
2. Перейдите на `https://192.168.255.137`
3. Войдите в систему
4. Перейдите в настройки (⚙️)
5. Найдите кнопку черно-белого режима (⚫)
6. Переключите режим и проверьте работу

## **🔧 Если что-то пошло не так:**

### **Восстановление из резервной копии:**
```bash
# Остановите сервер
sudo systemctl stop your-flask-app

# Восстановите базу данных
cp dating_app_backup_YYYYMMDD_HHMMSS.db dating_app.db

# Запустите сервер
python app.py
```

### **Проверка статуса:**
```bash
# Проверьте, что сервер запущен
ps aux | grep python

# Проверьте логи
tail -f /var/log/your-app.log
```

## **📋 Что будет развернуто:**

1. **app.py** - обновленный код с черно-белым режимом
2. **dating_app.db** - база данных с новым полем grayscale_mode
3. **migrate_add_grayscale_mode.py** - скрипт миграции
4. **Новая функциональность:**
   - Кнопка черно-белого режима в настройках
   - Сохранение настройки в базе данных
   - Применение режима на всех страницах
   - Персистентность после перезагрузки
