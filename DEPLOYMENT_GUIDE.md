# 🚀 Руководство по развертыванию черно-белого режима на удаленном сервере

## 📋 **Что нужно скопировать на удаленный сервер:**

### 1. **Файлы кода (обязательно):**
```
app.py                           # Основной файл с изменениями
migrate_add_grayscale_mode.py     # Скрипт миграции базы данных
```

### 2. **База данных (отдельно!):**
```
dating_app.db                    # Файл базы данных SQLite
```

### 3. **Статические файлы (если есть изменения):**
```
static/                          # CSS, JS, изображения
uploads/                         # Загруженные пользователями файлы
```

## 🔧 **Пошаговый план развертывания:**

### **Шаг 1: Подготовка локальных файлов**
```bash
# Создайте архив с нужными файлами
tar -czf grayscale_deployment.tar.gz app.py migrate_add_grayscale_mode.py dating_app.db
```

### **Шаг 2: Копирование на удаленный сервер**
```bash
# Скопируйте архив на сервер
scp grayscale_deployment.tar.gz user@remote-server:/path/to/project/

# Или используйте rsync
rsync -avz app.py user@remote-server:/path/to/project/
rsync -avz migrate_add_grayscale_mode.py user@remote-server:/path/to/project/
rsync -avz dating_app.db user@remote-server:/path/to/project/
```

### **Шаг 3: На удаленном сервере**

#### **3.1. Остановите текущий сервер:**
```bash
# Найдите процесс
ps aux | grep python
# Остановите процесс
kill -9 <PID>
# Или если используете systemd
sudo systemctl stop your-flask-app
```

#### **3.2. Сделайте резервную копию:**
```bash
# Создайте резервную копию текущей базы данных
cp dating_app.db dating_app_backup_$(date +%Y%m%d_%H%M%S).db
```

#### **3.3. Замените файлы:**
```bash
# Распакуйте архив (если использовали)
tar -xzf grayscale_deployment.tar.gz

# Или скопируйте файлы вручную
cp app.py /path/to/project/
cp migrate_add_grayscale_mode.py /path/to/project/
cp dating_app.db /path/to/project/
```

#### **3.4. Запустите миграцию (если нужно):**
```bash
# Если база данных на сервере старая, запустите миграцию
python migrate_add_grayscale_mode.py
```

#### **3.5. Проверьте права доступа:**
```bash
# Убедитесь, что файлы имеют правильные права
chmod 644 app.py
chmod 644 dating_app.db
chmod 755 migrate_add_grayscale_mode.py
```

#### **3.6. Запустите сервер:**
```bash
# Запустите Flask приложение
python app.py
# Или если используете systemd
sudo systemctl start your-flask-app
```

## ⚠️ **Важные моменты:**

### **Безопасность:**
- **Сделайте резервную копию** базы данных перед заменой
- **Проверьте права доступа** к файлам
- **Убедитесь, что сервер остановлен** перед заменой файлов

### **Проверка:**
- **Проверьте логи** сервера на ошибки
- **Протестируйте** черно-белый режим в браузере
- **Убедитесь**, что все функции работают

### **Откат (если что-то пошло не так):**
```bash
# Восстановите резервную копию базы данных
cp dating_app_backup_*.db dating_app.db
# Восстановите старую версию app.py
# Перезапустите сервер
```

## 🧪 **Тестирование на удаленном сервере:**

1. **Откройте браузер** и перейдите на адрес сервера
2. **Войдите в систему**
3. **Перейдите в настройки** (⚙️)
4. **Найдите кнопку черно-белого режима** (⚫)
5. **Переключите режим** и проверьте работу
6. **Обновите страницу** - режим должен сохраниться
7. **Перейдите на другие страницы** - режим должен работать везде

## 📞 **Если возникли проблемы:**

1. **Проверьте логи сервера** в терминале
2. **Проверьте права доступа** к файлам
3. **Убедитесь, что база данных** содержит поле `grayscale_mode`
4. **Проверьте, что сервер запущен** и доступен
