# ⚫ Руководство по черно-белому режиму

## 🎯 Описание функциональности

Добавлена кнопка для переключения сайта в черно-белый режим в настройках пользователя. Эта функция позволяет пользователям переключать весь интерфейс в черно-белый режим для лучшей читаемости или по личным предпочтениям.

## ✨ Что добавлено

### 1. **Кнопка в настройках**
- Новая настройка "⚫ Черно-белый режим" в разделе настроек
- Кнопка переключения с визуальной обратной связью
- Сохранение настройки в базе данных

### 2. **CSS стили**
- Глобальные CSS стили для черно-белого режима
- Поддержка всех браузеров (webkit, moz, ms, o)
- Применение фильтра `grayscale(100%)` ко всем элементам

### 3. **JavaScript функциональность**
- Автоматическое применение режима при загрузке страниц
- Переключение режима в реальном времени
- Сохранение настройки через API

### 4. **API поддержка**
- Обновлен API `/api/get_settings` для получения настройки
- Обновлен API `/api/update_settings` для сохранения настройки
- Добавлено поле `grayscale_mode` в базу данных

## 🎨 Внешний вид

### Кнопка в настройках
- **Выключен**: ⚪ (белый круг) - серый фон
- **Включен**: ⚫ (черный круг) - черный фон

### Применение режима
- При включении: весь сайт становится черно-белым
- При выключении: возвращается к цветному режиму
- Режим применяется ко всем страницам приложения

## 🔧 Технические детали

### База данных
- Добавлено поле `grayscale_mode` в таблицу `user_settings`
- Значение по умолчанию: `0` (выключен)
- Тип: `INTEGER`

### CSS классы
```css
.grayscale-mode {
    filter: grayscale(100%);
    -webkit-filter: grayscale(100%);
    -moz-filter: grayscale(100%);
    -ms-filter: grayscale(100%);
    -o-filter: grayscale(100%);
}
```

### JavaScript функции
- `applyGlobalGrayscaleMode()` - применяет режим глобально
- `toggleGrayscale()` - переключает режим
- `updateGrayscaleAppearance()` - обновляет внешний вид кнопки

## 📱 Использование

### Для пользователей
1. Перейдите в **Настройки** (⚙️)
2. Найдите настройку **"⚫ Черно-белый режим"**
3. Нажмите на кнопку для переключения
4. Режим применится ко всему сайту

### Для разработчиков
- Настройка сохраняется в `user_settings.grayscale_mode`
- Применяется автоматически при загрузке любой страницы
- Работает на всех страницах приложения

## 🎯 Преимущества

- **Доступность**: Улучшает читаемость для пользователей с нарушениями зрения
- **Экономия батареи**: На OLED экранах черно-белый режим экономит энергию
- **Личные предпочтения**: Пользователи могут выбрать комфортный режим
- **Глобальное применение**: Режим работает на всех страницах сайта
