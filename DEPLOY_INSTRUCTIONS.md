## 🔧 Настройки для деплоя:

### 1. Переменные окружения (.env файл):

```bash
# Основной домен (ОБЯЗАТЕЛЬНО!)
DEPLOY_DOMAIN=https://your-domain.com

# ЮKassa настройки
YOOKASSA_SHOP_ID=your_shop_id
YOOKASSA_SECRET_KEY=your_secret_key
YOOKASSA_TEST_MODE=False  # True для тестов, False для продакшена

# Безопасность
SECRET_KEY=your-very-secure-secret-key-here

# Flask настройки
FLASK_ENV=production
FLASK_DEBUG=False

# База данных
DATABASE_URL=sqlite:///dating_app.db

# Загрузки
UPLOAD_FOLDER=/var/www/uploads
```

### 2. Установка зависимостей:

```bash
pip install -r requirements.txt
```

### 3. Создание директорий:

```bash
mkdir -p uploads
chmod 755 uploads
```

### 4. Запуск приложения:

```bash
python app.py
```
