# 🔧 Руководство по отладке времени жизни анкет

## Проблема
Анкеты удаляются не через установленное время, а через фиксированные 30 минут, независимо от изменения настроек.

## Причины проблемы

### 1. **Сервер не перезапущен**
Самая частая причина! После изменения переменных `PROFILE_LIFETIME_HOURS` или `PENDING_PROFILE_LIFETIME_HOURS` в файле `app.py` **ОБЯЗАТЕЛЬНО нужно перезапустить Flask-сервер**.

```python
# Строки 36-37 в app.py
PROFILE_LIFETIME_HOURS = 10  # Измените это значение
PENDING_PROFILE_LIFETIME_HOURS = 10  # И это тоже
```

**⚠️ ВАЖНО:** Flask не подхватывает изменения глобальных переменных автоматически!

### 2. **Неправильные комментарии**
Раньше комментарии в коде говорили "30 минут" при значении 10 часов - это создавало путаницу. Сейчас это исправлено.

### 3. **Разница во времени создания**
- **Временная анкета (PendingProfile)** создается при заполнении формы
- **Основная анкета (Profile)** создается после оплаты с новым `created_at`
- Время жизни основной анкеты начинает отсчитываться ПОСЛЕ оплаты

## Решение

### Шаг 1: Проверьте текущие настройки
Откройте диагностическую страницу:
```
http://ваш-сервер:5000/debug/lifetime-settings
```

Эта страница показывает:
- ✅ Текущие значения `PROFILE_LIFETIME_HOURS` и `PENDING_PROFILE_LIFETIME_HOURS`
- ✅ Список всех анкет с их возрастом и оставшимся временем
- ✅ Какие анкеты будут удалены при следующей очистке
- ✅ Автоматически обновляется каждые 10 секунд

### Шаг 2: Измените время жизни
Отредактируйте файл `app.py`, строки 36-37:

```python
# Для 1 часа:
PROFILE_LIFETIME_HOURS = 1
PENDING_PROFILE_LIFETIME_HOURS = 1

# Для 30 минут:
PROFILE_LIFETIME_HOURS = 0.5
PENDING_PROFILE_LIFETIME_HOURS = 0.5

# Для 24 часов (1 день):
PROFILE_LIFETIME_HOURS = 24
PENDING_PROFILE_LIFETIME_HOURS = 24
```

### Шаг 3: Перезапустите сервер
```bash
# Остановите сервер (Ctrl+C)
# Запустите снова
python app.py
```

### Шаг 4: Проверьте в логах
При запуске сервер выведет:
```
⏰ Время жизни оплаченной анкеты: X часов
⏰ Время жизни временной анкеты: Y часов
```

## Частые вопросы

### Q: Почему анкета удаляется раньше, чем должна?
**A:** Проверьте:
1. Сервер был перезапущен после изменения настроек?
2. В логах выводится правильное значение времени жизни?
3. Время `created_at` анкеты корректное? (проверьте на `/debug/lifetime-settings`)

### Q: Временная анкета удаляется, а оплаченная нет - почему?
**A:** Это правильное поведение! Временная анкета удаляется после оплаты и создается новая оплаченная анкета с новым `created_at`.

### Q: Как установить разное время для оплаченных и временных анкет?
**A:** Измените значения отдельно:
```python
PROFILE_LIFETIME_HOURS = 24  # Оплаченные живут 24 часа
PENDING_PROFILE_LIFETIME_HOURS = 1  # Временные живут 1 час
```

### Q: Анкета должна жить 1 час, но удаляется через 30 минут
**A:** 
1. Проверьте значение на `/debug/lifetime-settings`
2. Если там показано 0.5 вместо 1 - вы не перезапустили сервер
3. Если показано 1, но удаляется через 30 минут - проверьте `created_at` анкеты

## Техническая информация

### Две модели анкет:
1. **PendingProfile** - временная анкета до оплаты
   - Создается при заполнении формы
   - Удаляется через `PENDING_PROFILE_LIFETIME_HOURS`
   - Удаляется также после успешной оплаты

2. **Profile** - основная оплаченная анкета
   - Создается после оплаты с НОВЫМ `created_at`
   - Удаляется через `PROFILE_LIFETIME_HOURS`
   - Имеет поле `is_paid = True`

### Функции очистки:
- `cleanup_expired_profiles()` - удаляет оплаченные анкеты
- `cleanup_expired_pending_profiles()` - удаляет временные анкеты
- `periodic_cleanup()` - вызывает обе функции каждые 5 минут

### Порядок действий при оплате:
```python
1. Пользователь создает временную анкету (PendingProfile)
2. Пользователь оплачивает
3. Создается новая основная анкета (Profile) с created_at = сейчас
4. Удаляется временная анкета (PendingProfile)
5. Таймер жизни основной анкеты начинает отсчет ОТ МОМЕНТА ОПЛАТЫ
```
